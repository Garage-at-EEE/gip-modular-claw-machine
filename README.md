# gip-modular-claw-machine
Garage participates in major outreach activities and showcases throughout the year, creating opportunities for interactive projects that can engage visitors while demonstrating what members can build.
This project aims to design and construct a modular claw machine from the ground up. Members will work across mechanical design, electronics, PCB development and embedded programming to create a complete electromechanical system. The structure and controls will be designed so the platform can be customised or expanded in future.
